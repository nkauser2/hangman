# Hangman 

Language: The program's main language will be Python.

How the program is run: The user will start the game from the terminal (using python hangman.py).

How the program is tested: Automated testing will be used and it will test on reading word.txt and splitting each line into a word and category. It will check a guess, whether there's any invalid inputs or repeated guesses, test if hints appear after 2 and 4 missed guesses, and decide the win or loss at the right time. All tests must pass and a skipped test doesnt count 

What must never happen: Never use or require API keys, paid services/payments, or user accounts. Never change word.txt without asking or do anything without the user's permission and approval.
