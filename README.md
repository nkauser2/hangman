# Hangman

## What the game does

Hangman is a simple spelling game you play in the terminal: guess a hidden word one letter at a time before the hangman drawing is finished. You get 5 wrong guesses, with hints after 2 and 4 misses (the first letter, then the word's category).

## Requirements

Python 3. The tests also need pytest (`pip install pytest`).

## How to run it

```
python hangman.py
```

## How to run the tests

```
python -m pytest
```
