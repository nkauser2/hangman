# Problem
A child needs a casual, low-stress way of practicing their spelling. They need something to test out their brain and sharpen their spelling skills in a way that will progressively help them by giving hints and give them chances to get the word correct (unlike using a dictionary or flashcards).  

# Initial requirements

**R1**
The program must pick a word from a built-in list and have a blank for each letter of the word to be filled in.

**R2**
The program must show which letters have already been guessed once user guesses them, regardless of if they are right or wrong. If player already guessed letter, say "already guessed."

**R3**
The program must have a body part added to a hangman for every incorrect letter guessed. Drawing is completed when user runs out of guesses. 

**R4** 
The program must give 5 missed guesses the user can get before word is revealed. After that, the word is revealed and the game ends. 

**R5**
The program must provide first hint of first letter of word after 2 wrong guesses and another hint of the word's category after 4 wrong guesses. Every word in list has a category.

**R6** 
The program must end in a congratulatory message if word is guessed correctly. 

**R7**
The program must end in a "try again next time" message if word is not guessed correctly.
